Features

A drawing tool that knows it's a system.

Sessions, folders, tabs

One project holds a whole system: sessions arranged in a folder tree, opened as tabs, each with its own notes. Start a session blank or from a saved block.

Technology icons — and yours

300+ language, framework and database marks plus the official AWS, Azure and Google Cloud sets, searchable from a panel inside the canvas. Add your own SVG or PNG logos; they follow you into every project.

Saved blocks

Select a few shapes, press Ctrl+Shift+B, name them. Blocks are shared across every project; starter blocks get you going.

Properties, links, inventory

Give any element a title, type, tags and a description, link it to another session or a URL, then see everything in one table — filter by tag, show on canvas, export CSV.

Looks from types

Pick a type — Service, Data, External, Actor — and the shape takes a matching look on a soft, consistent palette. One undo step if you disagree.

Search & command palette

Ctrl+K finds sessions, element text, tags and notes across the whole project, and runs every command without a menu hunt.

Tidy up

Boxes connected right but placed badly? Arrange the selection or the whole session in layers along the arrows — groups move together, arrows are redrawn.

Mermaid import

Paste a Mermaid flowchart, sequence or class diagram and insert it as editable shapes. Converted on your machine; nothing is sent anywhere.

Presentation mode

Press F5: full screen, one step per session or per frame, arrow keys to move, session notes at hand, Esc puts everything back.

Export

PNG at 1×–3×, SVG, PDF per session or the whole project, copy to clipboard — or one self-contained HTML page with every session that opens anywhere.

Bring your Excalidraw files

Open or drop .excalidraw drawings and images; they become sessions and canvas elements. .canya files open with a double-click.

Minimap

A small overview in the corner shows the whole session and where you are in it. Click or drag to jump; Ctrl+Shift+M hides it.

Nothing lost by accident

Deleted a session? Undo from the notice. Every save keeps a bounded local history you can preview and restore — and pasted screenshots are shrunk so project files stay small.

Safe with synced folders

Keep projects in Dropbox, iCloud or a Git checkout. If the file changes outside Canya you're asked — reload or keep yours — never silently overwritten.

Specification

Built around one file, not a database.

Plain, versioned file format

Every project is one .canya file — a versioned JSON envelope you can back up, diff, or move by hand. No hidden state directory, no database.

A real canvas, not a clone

Diagrams are drawn on an embedded Excalidraw canvas — the same hand-drawn shapes and tools, running natively inside the desktop app.

Sessions, folders, tabs

Diagrams live in sessions, arranged into a reorderable folder tree and opened as tabs. Element properties, links and notes live in the same file, next to the drawing.

Autosave that can't half-write

Autosave plus manual save (Ctrl/Cmd+S), written atomically to disk. A save is never left half-finished if the app closes mid-write.

No network, on principle

Nothing calls out while you work. Two narrow, documented exceptions: importing a project from a public https:// link you paste, and checking this site for a signed update at startup (which you can turn off). Nothing else makes a request.

Native on every desktop

A Tauri shell, not a wrapped browser tab — native window chrome and file dialogs on macOS, Windows, and Linux.
